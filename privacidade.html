Política de Privacidade — QG Finanças

Última atualização: 07/09/2026

QG Finanças é uma aplicação pessoal de gestão financeira, mantida por um único desenvolvedor para uso próprio e de pessoas convidadas por ele. Este documento explica quais dados o app trata e como.

Quais dados são coletados

  • Conta: e-mail e nome, via login com senha ou Google (Firebase Authentication).
  • Dados financeiros: lançamentos, gastos, entradas, contas, cartões, cofrinhos, investimentos e pendências que você mesmo cadastra no app.
  • Avatar: imagem de perfil opcional, se você escolher enviar uma.
  • Chaves de API: se você configurar o assistente "Julius", sua própria chave de API da Anthropic (Claude) fica salva no seu documento no banco de dados, nunca compartilhada com outros usuários.

Onde os dados ficam armazenados

Tudo fica hospedado no Firebase (Google Cloud): autenticação via Firebase Authentication, dados financeiros no Cloud Firestore e o avatar no Firebase Storage. As regras de segurança do banco garantem que cada conta só lê e escreve os próprios dados — nem o desenvolvedor consegue acessar os dados de outra conta pelo app.

Assistente Julius (Inteligência Artificial)

Quando você usa o Julius — chat, leitura de comprovante por foto ou leitura de extrato bancário em PDF/texto — as mensagens e o conteúdo enviado (foto, PDF ou texto do extrato) são transmitidos diretamente do seu navegador para a API da Anthropic (Claude), usando a chave de API que você mesmo cadastrou. Esses dados não passam por nenhum servidor do QG Finanças além do próprio Firebase onde ficam guardados os lançamentos resultantes.

O reconhecimento de voz (ditado por microfone) usa a funcionalidade nativa do navegador (Web Speech API) — o áudio é processado pelo próprio navegador/sistema operacional, não pelo QG Finanças.

Integração com Google Agenda (opcional)

Se você conectar sua conta do Google Agenda, o app pede permissão restrita apenas a eventos (calendar.events) mais e-mail/perfil básico. O token de acesso fica salvo somente no armazenamento local do seu navegador (não é sincronizado entre aparelhos nem enviado ao banco de dados) — apenas a informação "conectado" e o e-mail da conta ficam salvos no seu perfil.

Compartilhamento com terceiros

Os dados não são vendidos nem compartilhados com terceiros para fins de marketing ou publicidade. O único envio a terceiros é o descrito acima (Anthropic, quando você usa o Julius, e Google, para autenticação e agenda opcional), estritamente para o funcionamento das funcionalidades que você ativa.
